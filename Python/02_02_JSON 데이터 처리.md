# Python 2장 2교시 – JSON 데이터 처리

## 1. 핵심 개념

**JSON(JavaScript Object Notation)** 은 프로그램 간 데이터를 저장하거나 전달하기 위한 텍스트 기반 데이터 형식이다.

Marble AIOps에서는 Zabbix 장애 정보를 Python으로 전달하고 분석할 때 활용한다.

### JSON과 Python 딕셔너리 차이

| 구분 | JSON | Python |
|---|---|---|
| 데이터 형식 | JSON 텍스트 | 딕셔너리 등 객체 |
| 참 | `true` | `True` |
| 거짓 | `false` | `False` |
| 값 없음 | `null` | `None` |

## 2. 핵심 Python 문법

Python은 기본 제공되는 `json` 모듈을 사용한다.

```python
import json
```

| 함수 | 역할 |
|---|---|
| `json.load()` | JSON 파일 → Python 객체 |
| `json.loads()` | JSON 문자열 → Python 객체 |
| `json.dump()` | Python 객체 → JSON 파일 |
| `json.dumps()` | Python 객체 → JSON 문자열 |

**암기:** `load`는 읽기, `dump`는 저장·변환, 끝에 `s`가 붙으면 문자열 처리.

### 주요 옵션

- `encoding="utf-8"` : 파일의 문자 인코딩 지정
- `ensure_ascii=False` : 한글 등을 그대로 저장
- `indent=2` : JSON 들여쓰기 공백 2칸

## 3. 실습 – Marble 장애 JSON 분석

**목표:** 장애 JSON을 읽고 CPU 상태를 판단한 뒤 결과를 JSON 파일로 저장한다.

### 장애 데이터 (alert.json)

```json
{
  "host": "was01",
  "metrics": {
    "cpu": 91.5,
    "memory": 72
  },
  "severity": "HIGH"
}
```

### Python 분석 코드

```python
import json

# 1. JSON 파일 읽기
with open("alert.json", "r", encoding="utf-8") as file:
    alert = json.load(file)

# 2. 데이터 추출
host = alert["host"]
cpu = alert["metrics"]["cpu"]

# 3. CPU 상태 판단
if cpu >= 90:
    status = "CRITICAL"
elif cpu >= 80:
    status = "WARNING"
else:
    status = "NORMAL"

# 4. 분석 결과 생성
report = {
    "host": host,
    "cpu": cpu,
    "status": status
}

# 5. JSON 파일 저장
with open("result.json", "w", encoding="utf-8") as file:
    json.dump(report, file, ensure_ascii=False, indent=2)

print(f"{host} CPU: {cpu}% | {status}")
```

### 실행 및 검증

```bash
python3 analyze_alert.py
python3 -m json.tool result.json
cat result.json
```

예상 결과:

```text
was01 CPU: 91.5% | CRITICAL
```

`result.json`:

```json
{
  "host": "was01",
  "cpu": 91.5,
  "status": "CRITICAL"
}
```

## 4. 동작 원리

1. `json.load()`로 JSON 파일을 읽어 Python 딕셔너리로 변환한다.
2. `alert["metrics"]["cpu"]`로 중첩된 CPU 값을 조회한다.
3. `if·elif·else`로 CPU 사용률을 판단한다.
4. 분석 결과를 딕셔너리에 저장한다.
5. `json.dump()`로 JSON 파일을 생성한다.

## 5. 주요 오류와 해결 방법

| 오류 | 원인 | 해결 방법 |
|---|---|---|
| `FileNotFoundError` | 파일 없음 | `pwd`, `ls`로 경로 확인 |
| `JSONDecodeError` | JSON 문법 오류 | `python3 -m json.tool` 검사 |
| `KeyError` | 존재하지 않는 Key | Key 확인, `.get()` 활용 |
| `TypeError` | 데이터 자료형 불일치 | `type()`으로 확인 |
| `UnicodeDecodeError` | 인코딩 불일치 | 파일 인코딩 확인 |
