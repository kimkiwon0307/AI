### 1. 비교 연산자(Comparison Operator)란?

비교 연산자는 두 값을 비교하여 `True` 또는 `False`를 반환하는 연산자이다.

예를 들어 CPU 사용률이 90% 이상인지 확인할 수 있다.

```python
cpu_usage = 95

print(cpu_usage >= 90)
# True
```

#### 주요 비교 연산자

| 연산자 | 의미 | 예시 |
|---|---|---|
| `==` | 두 값이 같다 | `10 == 10` |
| `!=` | 두 값이 다르다 | `10 != 20` |
| `>` | 왼쪽이 크다 | `95 > 90` |
| `<` | 왼쪽이 작다 | `70 < 90` |
| `>=` | 크거나 같다 | `90 >= 90` |
| `<=` | 작거나 같다 | `80 <= 90` |

**주의:**
- `=` : 변수에 값을 할당
- `==` : 두 값이 같은지 비교

### 2. 조건문(if)이란?

조건문은 특정 조건의 참·거짓에 따라 실행할 코드를 결정하는 문법이다.

#### 기본 문법

```python
if 조건식:
    실행할_코드
```

#### 예시 — CPU 사용률 판단

```python
cpu_usage = 95

if cpu_usage >= 90:
    print("CPU 위험")
```

실행 결과:

```text
CPU 위험
```

CPU 사용률이 90 이상이면 조건이 참이므로 경고를 출력한다.

#### 들여쓰기(Indentation)

Python은 들여쓰기로 코드 블록을 구분한다.

```python
if cpu_usage >= 90:
    print("CPU 위험")
    print("관리자 확인 필요")

print("점검 완료")
```

`if` 아래의 들여쓴 코드는 조건이 참일 때만 실행한다.

마지막 `print("점검 완료")`는 조건과 관계없이 실행한다.

**핵심:** Python에서는 일반적으로 공백 4칸을 이용해 들여쓰기를 구분한다.

### 3. if · elif · else의 차이

| 문법 | 의미 |
|---|---|
| `if` | 첫 번째 조건 확인 |
| `elif` | 앞선 조건이 거짓일 때 추가 조건 확인 |
| `else` | 앞선 조건이 모두 거짓일 때 실행 |

#### CPU 상태 판단 예시

```python
cpu_usage = 85

if cpu_usage >= 90:
    print("위험")
elif cpu_usage >= 70:
    print("경고")
else:
    print("정상")
```

실행 결과:

```text
경고
```

#### 동작 순서

1. `85 >= 90` → False
2. `85 >= 70` → True
3. `"경고"` 출력
4. 나머지 조건은 검사하지 않음

**핵심:** if-elif-else는 위에서부터 조건을 확인하고 처음 참이 된 분기만 실행한다.

### 4. 논리 연산자(and, or, not)

논리 연산자는 여러 조건을 결합할 때 사용한다.

| 연산자 | 의미 | 예시 |
|---|---|---|
| `and` | 모든 조건이 참 | CPU 높음 AND 서비스 장애 |
| `or` | 하나라도 참 | CPU 높음 OR 메모리 높음 |
| `not` | 참·거짓 반전 | 서비스가 실행 중이지 않음 |

#### ① and

```python
cpu_usage = 95
status = "ERROR"

if cpu_usage >= 90 and status == "ERROR":
    print("CPU 및 서비스 장애")
```

두 조건이 모두 참이므로 메시지를 출력한다.

#### ② or

```python
cpu_usage = 95
memory_usage = 40

if cpu_usage >= 90 or memory_usage >= 90:
    print("자원 사용률 경고")
```

CPU와 메모리 중 하나라도 90 이상이면 경고한다.

#### ③ not

```python
is_running = False

if not is_running:
    print("서비스 중단")
```

`not`은 True와 False를 반대로 만든다.

### 5. 반복문(Loop)이란?

반복문은 같은 종류의 작업을 여러 번 실행하기 위한 문법이다.

Python에는 대표적으로 `for`와 `while`이 있다.

| 구분 | for | while |
|---|---|---|
| 반복 기준 | 리스트 등 반복 가능한 데이터 | 조건식 |
| 활용 | 여러 서버 순서대로 점검 | 특정 조건에서 재시도 |
| 주의사항 | 처리할 원소 확인 | 무한 반복 방지 |

---

### 6. for 반복문

`for`는 리스트 등의 데이터를 하나씩 꺼내 반복 실행한다.

#### 기본 문법

```python
for 변수 in 반복할_데이터:
    실행할_코드
```

#### Marble 서버 목록 예시

```python
servers = ["WEB01", "WEB02", "WAS01", "WAS02"]

for server in servers:
    print(server)
```

실행 결과:

```text
WEB01
WEB02
WAS01
WAS02
```

#### 코드 해설

- `servers` : 전체 서버 목록
- `server` : 현재 반복에서 처리하는 서버 하나
- `in` : 리스트에서 원소를 하나씩 가져오는 반복 문법
- `print(server)` : 현재 서버 이름 출력

**핵심:** 서버가 여러 대여도 `for` 반복문을 이용하면 동일한 코드를 반복 작성할 필요가 없다.

---

### 7. range() 함수

`range()`는 일정한 범위의 정수를 생성하는 객체를 반환하며 반복문에서 자주 사용한다.

```python
for number in range(5):
    print(number)
```

실행 결과:

```text
0
1
2
3
4
```

#### 시작점 지정

```python
for number in range(1, 6):
    print(number)
```

실행 결과:

```text
1
2
3
4
5
```

**주의:** `range(1, 6)`은 1부터 5까지이며 마지막 숫자 6은 포함하지 않는다.

---

### 8. while 반복문

`while`은 조건식이 참인 동안 코드를 반복 실행한다.

#### 기본 문법

```python
while 조건식:
    실행할_코드
```

#### 실습 — 3회 반복

```python
count = 1

while count <= 3:
    print(f"점검 {count}회")
    count += 1
```

실행 결과:

```text
점검 1회
점검 2회
점검 3회
```

`count += 1`은 다음 코드와 같다.

```python
count = count + 1
```

반복할 때마다 count 값을 증가시킨다.

**주의:** 종료 조건을 고려하지 않으면 무한 반복이 발생할 수 있다.

### 9. break와 continue

반복문에서 반복 흐름을 제어할 때 사용한다.

| 문법 | 역할 |
|---|---|
| `break` | 현재 반복문 전체 종료 |
| `continue` | 현재 반복만 건너뛰고 다음 반복 진행 |

#### break 예시

```python
servers = ["WEB01", "WEB02", "WAS01", "WAS02"]

for server in servers:
    if server == "WAS01":
        print("WAS01 발견")
        break

    print(server)
```

실행 결과:

```text
WEB01
WEB02
WAS01 발견
```

WAS01을 발견하면 반복을 종료하므로 WAS02는 처리하지 않는다.

#### continue 예시

```python
servers = ["WEB01", "WEB02", "WAS01", "WAS02"]

for server in servers:
    if server == "WAS01":
        continue

    print(server)
```

실행 결과:

```text
WEB01
WEB02
WAS02
```

WAS01만 건너뛰고 다음 원소를 계속 처리한다.

### 10. for + if + Dictionary 결합

서버별 상태를 딕셔너리로 저장하고 리스트로 관리할 수 있다.

```python
servers = [
    {"name": "WEB01", "status": "NORMAL"},
    {"name": "WEB02", "status": "NORMAL"},
    {"name": "WAS01", "status": "ERROR"},
    {"name": "WAS02", "status": "NORMAL"}
]

for server in servers:
    if server["status"] == "ERROR":
        print(f"장애 서버: {server['name']}")
```

실행 결과:

```text
장애 서버: WAS01
```

#### 동작 원리

1. `for`가 서버 딕셔너리를 하나씩 가져온다.
2. `server["status"]`로 상태를 확인한다.
3. 상태가 ERROR이면 `if` 조건이 참이 된다.
4. 해당 서버의 이름을 출력한다.

**핵심:** 반복문과 조건문을 결합하면 여러 서버의 상태를 자동으로 구분할 수 있다.

### 11. Marble 장애 서버 자동 추출 실습

#### 실습 목표

- 서버 목록 순서대로 확인
- 서비스 장애 여부 판단
- CPU 사용률 판단
- 점검이 필요한 서버를 별도 리스트에 저장

#### 파일 생성

```bash
mkdir -p ~/python-lab/lesson03
cd ~/python-lab/lesson03
nano marble_incident.py
```

#### Python 코드

```python
# Marble 서버 상태 점검

servers = [
    {"name": "WEB01", "status": "NORMAL", "cpu": 35},
    {"name": "WEB02", "status": "NORMAL", "cpu": 92},
    {"name": "WAS01", "status": "ERROR", "cpu": 45},
    {"name": "WAS02", "status": "NORMAL", "cpu": 55},
    {"name": "DB01", "status": "NORMAL", "cpu": 30}
]

incidents = []

print("===== Marble 장애 점검 =====")

for server in servers:

    if server["status"] != "NORMAL":
        incidents.append(server["name"])
        print(f"[서비스 상태 이상] {server['name']}")

    elif server["cpu"] >= 90:
        incidents.append(server["name"])
        print(f"[CPU 위험] {server['name']}")

print("\n===== 점검 결과 =====")

print(f"전체 서버: {len(servers)}대")
print(f"점검 필요 서버: {len(incidents)}대")

for name in incidents:
    print(f"- {name}")

print("===== 점검 완료 =====")
```

#### 실행

```bash
python3 marble_incident.py
```

#### 실행 결과

```text
===== Marble 장애 점검 =====
[CPU 위험] WEB02
[서비스 상태 이상] WAS01

===== 점검 결과 =====
전체 서버: 5대
점검 필요 서버: 2대
- WEB02
- WAS01
===== 점검 완료 =====
```

#### 코드 핵심 해설

| 코드 | 의미 |
|---|---|
| `servers = [...]` | 서버 목록 저장 |
| `incidents = []` | 점검 필요 서버 저장용 빈 리스트 |
| `for server in servers:` | 서버를 하나씩 확인 |
| `if server["status"] != "NORMAL":` | 서비스 상태 이상 판단 |
| `elif server["cpu"] >= 90:` | CPU 위험 판단 |
| `incidents.append(...)` | 점검 대상 서버 추가 |
| `len(incidents)` | 점검 필요 서버 수 확인 |

현재 프로그램은 직접 입력한 가상 데이터를 검사한다.

실제 서버 상태를 자동으로 가져오는 기능은 이후 Linux 운영 자동화 및 API 과정에서 구현한다.
