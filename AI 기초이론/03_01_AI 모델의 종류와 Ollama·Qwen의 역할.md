
# AI 기초 이론 — 2장 3교시
## AI 모델의 종류와 Ollama·Qwen의 역할

### 1. 대표적인 LLM 모델

LLM(Large Language Model)은 대규모 데이터를 학습하여 질문 답변, 문서 요약, 코드 작성, 로그 분석 등의 작업을 수행하는 AI 모델이다.

| 모델 | 개발사 | 특징 |
|---|---|---|
| GPT | OpenAI | 질문 답변, 코드 작성, 문서 분석 등 |
| Qwen | Alibaba | 일반 언어 처리, 코드 작성, 로컬 실행 가능한 모델 제공 |
| Llama | Meta | 공개 가중치 모델을 제공하며 로컬 실행 가능 |

세 가지 모두 LLM 모델 계열이지만 모델별 성능, 비용, 실행 환경, 라이선스가 다르다.

**핵심:** GPT, Qwen, Llama는 AI 모델 계열의 이름이며, 사용 목적에 따라 적합한 모델을 선택해야 한다.

---

### 2. Ollama와 Qwen의 차이

Ollama와 Qwen은 서로 역할이 다르다.

| 구분 | Ollama | Qwen |
|---|---|---|
| 정체 | AI 모델 실행 프로그램 | AI 모델 |
| 역할 | 모델 다운로드·실행·관리·API 제공 | 질문 분석 및 답변 생성 |
| 직접 개발 | 필요 없음 | 필요 없음 |
| 활용 | Ubuntu 서버에 설치 | Ollama에서 실행 |

#### 동작 구조

```text
Ubuntu 서버
    │
    └── Ollama (AI 실행 프로그램)
            │
            └── Qwen (AI 모델)
                    │
                    └── 질문 분석 및 답변 생성
```

기존에 배운 Java 실행 환경과 애플리케이션의 관계처럼 이해할 수 있다.

**핵심: Ollama는 AI 모델을 실행하는 도구이고, Qwen은 실제 분석을 수행하는 모델이다.**

---

### 3. Ollama의 주요 기능

Ollama는 AI 모델을 로컬 PC나 서버에서 실행하고 관리하는 프로그램이다.

주요 기능:
- AI 모델 다운로드
- 모델 실행 및 대화
- 설치된 모델 목록 확인
- 실행 중인 모델 확인
- HTTP API 제공
- 모델 실행에 필요한 자원 관리

#### 대표 명령어

```bash
# Qwen 모델 다운로드
ollama pull qwen2.5-coder:7b

# Qwen 모델 실행 및 대화
ollama run qwen2.5-coder:7b

# 다운로드된 모델 목록 확인
ollama list

# 현재 메모리에 로드된 모델 확인
ollama ps
```

| 명령어 | 의미 |
|---|---|
| pull | 모델 다운로드 |
| run | 모델 실행 |
| list | 다운로드된 모델 목록 |
| ps | 메모리에 로드된 모델 확인 |

Ollama의 기본 로컬 API 주소:

`http://localhost:11434/api`

Python 프로그램은 이 API를 이용해 Qwen 모델에 질문을 전달하고 분석 결과를 받을 수 있다.

#### Python과 Ollama의 관계

```text
Python 프로그램
       ↓
Ollama API 호출
       ↓
Qwen 모델 추론(Inference)
       ↓
AI 분석 결과 생성
       ↓
Python이 결과 수신
```

**핵심:** Python은 AI와 기존 인프라를 연결하고, Ollama는 Qwen 모델을 실행한다.

### 4. 모델 이름의 1.5B, 3B, 7B는 무엇인가?

B는 Billion(10억)을 뜻하며 모델의 매개변수(Parameter) 수를 나타낸다.

매개변수는 학습된 패턴을 계산하는 데 사용되는 모델 내부 수치이다.

| 모델 크기 | 매개변수 수(대략) |
|---|---|
| 1.5B | 15억 개 |
| 3B | 30억 개 |
| 7B | 70억 개 |
| 14B | 140억 개 |
| 32B | 320억 개 |

일반적으로 모델이 커질수록 더 많은 메모리와 계산 자원이 필요하다.

하지만 **모델이 크다고 반드시 정확도가 높은 것은 아니다.**

모델의 학습 데이터, 구조, 특화 분야 등에 따라 성능이 달라진다.

---

### 5. 양자화(Quantization)란?

양자화는 모델의 수치를 더 적은 비트로 표현하여 파일 크기와 메모리 요구량을 줄이는 기술이다.

예를 들어 일부 수치를 16비트 대신 4비트로 표현할 수 있다.

**장점**
- 모델 크기 감소
- 메모리 사용량 절약
- 작은 컴퓨터에서도 비교적 큰 모델 실행 가능

**단점**
- 양자화 방식에 따라 답변 품질이 저하될 수 있음

모델 파일 크기와 실제 실행에 필요한 RAM 용량은 같지 않다.

---

### 6. AI 모델 실행에 필요한 하드웨어

| 구성 요소 | 역할 |
|---|---|
| CPU | AI 모델의 계산 수행 |
| RAM | 모델 가중치와 실행 데이터 보관 |
| GPU | 병렬 계산을 이용한 AI 추론 가속 |
| VRAM | GPU에서 모델과 계산 데이터 보관 |
| Disk | 다운로드한 모델 파일 저장 |

#### GPU가 반드시 필요한가?

아니다.

지원되는 AI 모델은 CPU만으로도 실행할 수 있다.

다만 모델이 크면 CPU 환경에서 답변 생성 속도가 느려질 수 있다.

GPU가 있으면 모델 추론을 가속할 수 있지만 VRAM 용량도 고려해야 한다.

**Marble 적용:** VMware Ubuntu에서 Ollama를 실행하려면 VM에 할당한 CPU·RAM과 호스트 PC 자원을 함께 확인해야 한다.

### 7. AI 모델을 선택할 때 확인할 사항

모델은 단순히 매개변수 수가 많다고 선택하는 것이 아니다.

#### ① 모델의 용도

| 모델 종류 | 주된 활용 |
|---|---|
| 일반 지시형 LLM | 질문 답변, 문서 분석, 장애 로그 설명 |
| 코드 특화 LLM | Python·Shell 코드 생성 및 분석 |
| 추론 특화 LLM | 복잡한 문제 해결과 단계별 분석 |
| 멀티모달 모델 | 텍스트와 이미지 등 여러 형태의 입력 처리 |

#### ② Base와 Instruct 모델

- Base: 대규모 데이터로 사전 학습된 기본 모델
- Instruct: 사용자의 지시사항을 잘 따르도록 추가 조정된 모델

장애 로그 분석과 보고서 생성을 위해서는 일반적으로 Instruct 모델부터 고려하는 것이 적합하다.

#### ③ 운영 환경

다음 항목도 고려해야 한다.

- CPU·RAM·GPU 사양
- 모델 메모리 사용량
- 응답 생성 속도
- 실제 장애 분석 정확도
- 한국어 지원 수준
- 사용 비용 및 라이선스

---

### 8. Ollama와 Qwen은 무료인가?

Ollama는 MIT 라이선스로 제공되는 오픈소스 소프트웨어이다.

Qwen 계열에도 무료로 다운로드할 수 있는 공개 가중치 모델이 있다.

예를 들어 Qwen2.5-Coder 7B는 Apache 2.0 라이선스로 공개되어 있다.

단, 모든 Qwen 모델의 라이선스가 동일한 것은 아니므로 모델별 확인이 필요하다.

**주의:** 프로그램과 모델이 무료여도 서버 운영 비용은 별도로 발생할 수 있다.

### 9. Marble AIOps에 적용

기존 Marble 프로젝트에 AI 분석 기능을 추가할 계획이다.

#### 최종 목표 구조

```text
Marble WEB/WAS/DB 장애 발생
              ↓
Zabbix 장애 감지
              ↓
Python 장애 정보 수집
              ↓
ELK 관련 로그 조회
              ↓
Python이 Ollama API 호출
              ↓
Ollama에서 Qwen 모델 실행
              ↓
Qwen이 장애 원인 가설 생성
              ↓
Python 복구 정책 및 안전 조건 검증
              ↓
허용된 단순 장애 자동 복구
              ↓
Health Check 및 Discord 알림
```

#### AI 모델 선택 계획

1. 소형 모델로 Ollama 설치 및 API 사용법 학습
2. PC 사양에 따라 3B·7B급 모델 실습
3. 동일한 장애 로그로 모델별 분석 결과 비교
4. 정확도, 속도, 메모리 사용량을 측정
5. Marble에 사용할 모델 선정

처음에는 Qwen2.5-Coder 1.5B 같은 소형 모델로 실행 구조를 학습할 수 있다.

실제 장애 분석에서는 7B 등 다른 모델과 비교하여 적합한 모델을 선택해야 한다.

**중요:** AI는 장애 원인을 추론하고 복구 방법을 추천한다. 실제 복구 명령은 사전에 검증된 안전한 정책에 따라 실행한다.

### 10. AI 서버 운영 시 확인할 사항

AI 서버 역시 일반 Linux 서버처럼 관리해야 한다.

- Ollama 서비스 정상 동작 여부
- CPU·RAM 사용률
- GPU·VRAM 사용률(사용 시)
- 모델 저장 디스크 용량
- API 연결 상태
- API 접근 권한 및 보안
- 추론 속도와 오류 발생 여부
- Zabbix를 통한 AI 서버 모니터링

특히 Ollama API를 인증이나 접근 제한 없이 외부 인터넷에 공개해서는 안 된다.

### 11. 이번 교시 핵심 개념

| 용어 | 의미 |
|---|---|
| GPT | OpenAI의 LLM 모델 계열 |
| Qwen | Alibaba의 LLM 모델 계열 |
| Llama | Meta의 LLM 모델 계열 |
| Ollama | AI 모델 실행 및 관리 프로그램 |
| Parameter | 모델 내부의 학습된 수치 |
| 7B | 약 70억 개의 매개변수 |
| Quantization | 모델 수치를 적은 비트로 표현해 자원 절약 |
| CPU | 모델 계산 수행 |
| RAM | 모델과 실행 데이터 보관 |
| GPU | 병렬 계산을 통한 추론 가속 |
| VRAM | GPU에서 사용하는 메모리 |
| Instruct | 지시를 따르도록 추가 조정된 모델 |

### 반드시 기억할 핵심 5가지

1. GPT, Qwen, Llama는 서로 다른 LLM 모델 계열이다.
2. **Ollama는 AI 실행 프로그램이고 Qwen은 AI 모델이다.**
3. 1.5B, 7B는 모델의 매개변수 규모를 나타낸다.
4. GPU 없이 CPU만으로도 일부 AI 모델을 실행할 수 있지만 속도와 메모리를 고려해야 한다.
5. Marble에 사용할 모델은 실제 장애 분석 품질과 하드웨어 자원을 비교해 선택해야 한다.
