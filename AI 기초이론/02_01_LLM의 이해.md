
# AI 기초 이론 — 2장 1교시
## LLM(대규모 언어 모델)의 이해

### 1. LLM이란 무엇인가?

LLM(Large Language Model)은 **대량의 텍스트와 코드 등을 학습하여 문장을 처리하고 새로운 답변을 생성하는 AI 모델**이다.

대표적인 LLM:
- GPT
- Qwen
- Llama

LLM으로 할 수 있는 작업:
- 질문에 답변
- 문서 요약 및 번역
- Python, Shell Script 등 코드 작성
- 오류 로그 분석
- 장애 원인 가설 및 대응 방법 생성

**핵심:** LLM은 Linux나 AWS 전용 프로그램이 아니라 다양한 언어 관련 작업을 수행할 수 있는 AI 모델이다.

---

### 2. LLM은 왜 등장했을까?

기존 규칙 기반 챗봇은 사람이 작성한 조건에 따라 답변한다.

예시:

```text
사용자: 비밀번호를 잊어버렸어요.
     ↓
"비밀번호" 키워드 감지
     ↓
미리 저장한 답변 출력
```

하지만 사용자가 "계정에 접근할 수 없어요"라고 질문하면 단순 키워드 방식으로는 처리하기 어려울 수 있다.

LLM은 학습한 언어 패턴과 문맥을 활용하여 표현이 달라도 관련된 답변을 생성할 수 있다.

#### Marble 프로젝트 예시

WAS01에서 다음 로그가 발생했다.

`Communications link failure`

- 규칙 기반: 미리 정의된 "DB 연결 오류" 메시지 출력
- LLM 활용: 로그, DB 상태, 네트워크 상태 등을 종합해 가능한 원인과 확인 방법 생성

**핵심:** LLM은 단순 키워드 검색을 넘어 문맥을 고려한 분석과 답변 생성에 활용된다.

---

### 3. LLM은 어떻게 만들어지는가?

LLM의 학습 과정은 다음과 같다.

```text
대규모 학습 데이터 준비
        ↓
사전 학습(Pre-training)
        ↓
추가 학습 및 조정
        ↓
학습된 LLM 완성
        ↓
모델 실행 및 활용
```

#### ① 사전 학습(Pre-training)

대량의 텍스트와 코드 등을 이용하여 언어적·기술적 패턴을 학습하는 과정이다.

대표적으로 다음에 올 토큰을 예측하도록 학습한다.

예시:

"Linux에서 프로세스를 확인하는 명령어는 ___"

→ `ps`가 적절한 답변 중 하나일 수 있다.

학습 과정에서 모델 내부의 가중치(Weight)가 조정된다.

**Weight(가중치):** 학습 과정에서 조정되는 모델 내부의 수치

#### ② 추가 학습 및 조정

사전 학습 이후 사용자의 지시를 더 잘 따르도록 모델을 추가로 학습하거나 조정할 수 있다.

예시:
- 질문에 적절하게 답변
- 요청한 형식으로 결과 출력
- 기술적 설명 생성

#### ③ 추론(Inference)

이미 학습된 모델에 새로운 질문을 입력하여 결과를 생성하는 과정이다.

우리는 Qwen을 처음부터 학습시키는 것이 아니라 **이미 학습된 모델을 이용해 추론을 수행**할 예정이다.

---

### 4. Transformer란 무엇인가?

Transformer는 현대적인 LLM에서 널리 사용되는 **인공신경망 구조**이다.

문장에 포함된 여러 단어와 정보 사이의 관계를 처리하는 데 활용된다.

예시:

"WAS01이 DB01에 연결하지 못했습니다. DB01의 MySQL 서비스가 중단되었습니다."

이 문장에서 WAS01의 연결 실패와 DB01의 서비스 중단이 서로 관련된 정보라는 것을 문맥상 처리할 수 있다.

#### Attention이란?

Attention은 Transformer에서 입력된 정보의 각 부분이 서로 얼마나 관련되는지를 계산하는 메커니즘이다.

| 개념 | 역할 |
|---|---|
| Transformer | 입력 문맥을 처리하는 신경망 구조 |
| Attention | 입력 정보 사이의 관련성을 계산 |
| Weight | 모델 내부에서 학습되는 수치 |

**핵심:** Transformer는 문맥을 처리하는 구조이고, Attention은 정보 간 관련성을 계산하는 핵심 메커니즘이다.

---

### 5. LLM은 어떻게 답변을 생성하는가?

GPT와 Qwen 같은 일반적인 LLM은 문맥을 바탕으로 **다음 토큰(Token)을 예측하는 과정을 반복**하여 답변을 생성한다.

```text
① 사용자 질문 입력
         ↓
② 입력 문장을 토큰으로 변환
         ↓
③ Transformer가 문맥 처리
         ↓
④ 다음 토큰의 확률 계산 및 선택
         ↓
⑤ 토큰 생성 반복
         ↓
⑥ 완성된 답변 출력
```

#### Token이란?

LLM이 텍스트를 처리하는 기본 단위이다.

문자, 단어 또는 단어의 일부 등이 토큰이 될 수 있다.

#### 예시

사용자 질문:

"MySQL 연결 오류가 발생했는데 무엇을 확인해야 하나요?"

LLM 답변:

"먼저 MySQL 서비스 상태와 3306 포트 연결 여부를 확인하세요."

이 답변은 학습한 패턴과 입력 문맥을 바탕으로 생성한 결과이다.

**중요:** 자연스러운 답변을 생성한다고 해서 내용이 반드시 정확하다는 의미는 아니다.

---

### 6. LLM은 왜 틀린 답변을 할까?

LLM은 실제 서버 상태를 자동으로 확인하는 프로그램이 아니다.

입력된 정보와 학습한 패턴을 이용하여 답변을 생성한다.

따라서 근거가 부족한 내용을 사실처럼 생성하는 **환각(Hallucination)**이 발생할 수 있다.

#### Marble 장애 예시

입력 로그:

`ERROR: Communications link failure`

AI가 "MySQL 서비스가 중단되었습니다"라고 답변했다고 가정하자.

그러나 실제 원인은 다음과 같을 수도 있다.

- MySQL 서비스 중단
- Security Group의 3306 포트 차단
- 네트워크 연결 문제
- MySQL bind-address 설정 오류

따라서 AI의 원인 분석은 가설로 취급하고, 실제 서버 상태를 확인하여 검증해야 한다.

**핵심:** LLM은 장애 분석을 지원하지만 실제 장애 원인을 항상 정확하게 판단하지는 못한다.

### 7. Ollama와 Qwen의 역할

| 기술 | 설명 |
|---|---|
| LLM | 대규모 언어 모델이라는 기술 종류 |
| Qwen | 이미 학습된 LLM 모델 계열 |
| Ollama | Qwen 같은 모델을 실행하고 API를 제공하는 프로그램 |
| Python | AI에 질문을 전달하고 결과를 처리하는 프로그램 |

동작 구조:

```text
Python 프로그램
       ↓
Ollama API 호출
       ↓
Qwen 모델 실행
       ↓
장애 정보 분석
       ↓
분석 결과 반환
       ↓
Python 프로그램
```

Ollama와 Qwen을 설치했다고 기존 서버의 상태를 자동으로 알 수 있는 것은 아니다.

Zabbix, ELK 등의 시스템에서 실제 운영 정보를 수집해 모델에 전달해야 한다.

---

### 8. Marble AIOps에서 LLM 활용

최종적으로 구축할 시스템은 다음과 같다.

```text
Marble 서버 장애 발생
          ↓
Zabbix 장애 감지
          ↓
Python 장애 정보 수집
          ↓
ELK 관련 로그 조회
          ↓
Ollama + Qwen (LLM)
          ↓
장애 원인 가설 및 대응 방법 생성
          ↓
Python 복구 정책 및 안전 조건 검증
          ↓
허용된 단순 장애 자동 복구
          ↓
Health Check 및 Discord 알림
```

#### 각 기술의 역할

- Zabbix: 장애 감지
- ELK: 로그 수집 및 검색
- Python: 장애 정보 수집과 자동화
- Ollama: AI 모델 실행
- Qwen: 장애 원인 분석
- 복구 정책 엔진: 안전 조건 확인 및 허용된 조치 실행
- Discord: 장애·복구 결과 알림

**중요:** AI가 생성한 명령어를 그대로 실행하는 것이 아니라, 사전에 검증된 복구 정책에 따라 실행한다.

### 9. 핵심 개념 정리

| 용어 | 의미 |
|---|---|
| LLM | 대규모 언어 모델 |
| Pre-training | 대규모 데이터로 모델을 사전 학습 |
| Weight | 모델 내부의 학습 가능한 수치 |
| Transformer | 문맥을 처리하는 신경망 구조 |
| Attention | 입력 정보 사이의 관련성을 계산 |
| Token | LLM이 텍스트를 처리하는 기본 단위 |
| Inference | 학습된 모델로 결과를 생성하는 과정 |
| Hallucination | 부정확하거나 근거 없는 내용을 생성하는 현상 |
| Ollama | AI 모델 실행 프로그램 |
| Qwen | 이미 학습된 LLM 모델 |

### 10. 반드시 기억할 핵심 5가지

1. **LLM은 대량의 데이터를 학습한 언어 모델이다.**
2. **Transformer는 문맥을 처리하고 Attention은 정보 간 관련성을 계산한다.**
3. **LLM은 다음 토큰을 예측하는 과정을 반복해 답변을 생성한다.**
4. **Qwen은 AI 모델이고 Ollama는 모델 실행 프로그램이다.**
5. **LLM은 실제 서버 상태를 자동으로 알지 못하므로 운영 정보를 전달하고 결과를 검증해야 한다.**
